## The through-line

The workshop teaches **Consider → Scope → Build**. The demo proves it: every object in the
demo world is traceable to a line in its scoping document, and the instructor can toggle
the world through its build stages (greybox → polish) live in the room.

## Starting the Claude Code build

Open a terminal in `demo/` and run `claude`, then:

> Read CLAUDE.md, SCOPE.md, BUILD_PLAN.md and world/aurora-station.brief.md. Then start Milestone 0.
